# AI

### Contents
This repository contains various AI and GEN AI projects, including agentic AI projects and POCs.

### Projects
- [AgenticAI-Tech-Docs-Generator](AgenticAI-Tech-Docs-Generator) — multi-agent TypeScript app that generates technical/functional specs from a repo or local folder.
- [agenticai-ui-automation-playwright-mcp](agenticai-ui-automation-playwright-mcp) — multi-agent UI automation/testing via Playwright MCP.
- [ServiceNow-Ticket-Completeness-Agent](ServiceNow-Ticket-Completeness-Agent) — rule-based agent that checks ServiceNow ticket completeness.
- [AgenticAI-Trip-Concierge-MicrosoftAgentFramework](AgenticAI-Trip-Concierge-MicrosoftAgentFramework) — C#/Blazor demo of the Microsoft Agent Framework's Sequential, Concurrent, GroupChat, and Handoff orchestration patterns, with the Handoff agent hosted live on Azure AI Foundry.
